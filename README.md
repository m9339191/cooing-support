# Cooing support & privacy

Public support and privacy information for Cooing: Baby Care Journal.

Languages: English, Korean, Japanese and Vietnamese. Neutral entry URLs choose the browser's first supported language, reuse an explicit selection, and fall back to English. Every page has direct language links and full localized content; the pages remain readable without JavaScript.

- Website: https://m9339191.github.io/cooing-support/
- Support: https://m9339191.github.io/cooing-support/support/
- Privacy: https://m9339191.github.io/cooing-support/privacy/
- Contact: it@bebriz.com

Edit `content.json`, `build.py` or `assets/`, then run `python3 build.py` and commit the generated static pages. GitHub Pages serves the main branch root. This repository contains no app source, signing credentials, private records or backup files.
